## 10. 验收口径（摘要）

| 域 | 验收标准 |
|---|---|
| 基座 | 后台可完成“建角色 → 配菜单 → 建用户 → 登录 → 看到对应菜单与按钮 → 越权接口 403”闭环 |
| 双权限 | 会员 Token 调后台接口 401；后台 Token 调会员接口 401；两套表无外键耦合 |
| CMS | 新建模型 → 建栏目 → 发文 → 审核 → 发布 → PC/H5 可见 → 下线不可见 |
| 会员 | 注册 → 登录 → 找回密码 → 改密后旧 Token 失效 → 个人中心可见 |
| 工作流 | 发起 → 待办 → 同意 / 驳回 → 状态回写 → 流程图可追踪 |
| 图片 | 上传 → 裁剪 → 水印 → 编辑器引用 → 替换 → 前台显示新图，旧图可回溯 |
| SaaS | 新建租户 → 初始化 → 子用户登录 → 只看到套餐内菜单 → A 租户查不到 B 租户数据（P6 开启后） |
| 单租户 | 关闭 SaaS 后启动：无租户表 / 接口 / 菜单，业务 `tenant_id=0`，`TenantContext` 正常 |
| 模块开关 | 关闭 CMS 后重启：无 CMS Bean、无 CMS 接口、无 CMS 表迁移、无 CMS 菜单、前端无路由 |
| JDK | 同一 jar 在 8/11/17 启动，冒烟用例全过；首发验收基线 8/11，17 只冒烟 |
| 部署 | `java -jar` + Nginx + MySQL / Redis 可完成登录、发文、上传、前台访问；后期 Docker 结果一致 |
| AI 工程 | AI 生成代码通过编译、单测、静态检查、依赖扫描与人工评审；核心链路有集成测试 |
| 多语言 | 切换 `zh-CN` / `en-US` 后后台、门户、CMS 内容均生效；缺翻译按回退链展示；发布语言包 5s 内生效 |
| 多数据库 | 同一份代码在 MySQL / PostgreSQL 启动并通过集成测试；达梦 / 金仓在客户环境完成核心流程 |
