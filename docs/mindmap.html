  Archived --> [*]

图片处理链路

flowchart LR
  U["选择图片"] --> C{"客户端裁剪?"}
  C -- 是 --> CROP["vue-cropper / Canvas<br/>x y w h rotate"]
  C -- 否 --> UP["上传原图"]
  CROP --> UP
  UP --> V["服务端校验<br/>魔数 / 大小 / 像素"]
  V --> H["SHA-256 去重"]
  H --> Q{"已存在"}
  Q -- 是 --> R["返回 fileId"]
  Q -- 否 --> O["存原图（不可变）"]
  O --> P["生成衍生图<br/>缩略 / 中图 / WebP"]
  P --> W{"水印策略"}
  W -- 开 --> WM["文字 / 图片水印"]
  W -- 关 --> SKIP["跳过"]
  WM --> DB["写 sys_file"]
  SKIP --> DB
  DB --> R
  R --> ED["编辑器插入 fileId"]
  ED --> REF["sys_file_ref 引用"]
  REF --> PUB["发布 / 前台展示"]

工作流审批时序

sequenceDiagram
  participant E as 编辑
  participant C as CMS
  participant W as Flowable
  participant A as 审核员
  participant P as 门户

  E->>C: 提交文章审核
  C->>C: 校验状态 / 锁版本
  C->>W: startProcess(businessKey=cms:123)
  W-->>C: 流程实例 ID
  C->>C: 状态改为待审核
  W->>A: 生成待办
  A->>W: 同意 / 驳回 + 意见
  W-->>C: 监听器回调
  alt 通过
    C->>C: 状态改为已发布
    C->>P: 发事件 / 删缓存
  else 驳回
    C->>C: 状态改为已驳回
    C->>E: 通知修改
  end
